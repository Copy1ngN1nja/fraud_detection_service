# ML Fraud Detection Service

DISCLAIMER

Сервис подготовлен в рамках выполнения домашнего задания в ШАД МТС 2026 по курсу ML-Ops.

Сервис предоставляет возможность классификации транзакций на обычные (класс 0) и мошеннические (класс 1),
с помощью предобученной модели LGBMClassifier. Кроме того, строится график плотности распределения предска-
занных вероятностей, а также сохраняются 5 лучших по улучшению качества признаков и процент вклада для каждого.

## Ключевые особенности

### Многоуровневое логирование
- Регистрация всех событий в файл `/app/logs/service.log`
- Консольный вывод для мониторинга в реальном времени
- 3 уровня детализации:
  - `INFO`: Основные этапы обработки
  - `DEBUG`: Детали преобразования данных
  - `ERROR`: Критические сбои с трейсбэками

### Пайплайн обработки данных (`preprocessing.py`)
1. **Временные признаки**:
   - Извлечение года, месяца, дня, часа и минуты
   - Удаление исходного timestamp
   
2. **Геопространственные расчеты**:
   - Расчет расстояния (км) между клиентом и мерчантом
   - Использование формулы гаверсинусов

3. **Категориальные переменные**:
   - Кодирование с помощью обученного CatBoostEncoder-а

4. **Числовые признаки**:
   - Импутация средними значениями
   - Логарифмирование с добавлением 1 для признаков `amount` и `population_city`

### Модельный слой (`scorer.py`)
- Порог классификации: 0.49
- Автоматическая загрузка модели при инициализации
- Батчевая обработка через `booster.predict` (возвращает "вероятности")

## Быстрый старт

### Требования
- Docker 20.10+
- 2 ГБ свободного места
- Порты: только файловая система

### Запуск сервиса

1. Соберите образ
```bash
docker build -t fraud_detector .
```
2. Запустите контейнер с монтированием томов
```bash
docker run -it --rm -v ./input:/app/input \
                    -v ./output:/app/output \
                    fraud_detector
```
3. После запуска сервиса (появления в логах сообщения: `__main__ - INFO - File observer started`) можно приступать к скорингу данных:
 - Разместите файл формата test.csv из соревнования https://www.kaggle.com/competitions/teta-ml-1-2025 в директории `./input`
 - Подождите выполнения препроцессинга и скоринга датасета (в логах будет указано название сформированного файла)
 - Подождите настройки стиля графика и его построения (в логах будет указано название файла, содержащего график плотности распределения предсказаний модели)
 - Подождите рассчета важности признаков (процент суммарного улучшения качества)
 - Полученные результаты моделирования и оценки будут выгружены сервисом в директорию `./output`
